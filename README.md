# Basic Calculator

A simple command-line calculator written in Python. Takes two numbers as input and prints out the sum, difference, product, power, division, remainder, and floor division — all in one go.

I built this while practicing Python basics (input handling, arithmetic operators, and simple conditionals).

## What it does

Given two numbers, it calculates:

- Sum
- Difference
- Product
- Power (a raised to b)
- Division
- Remainder (modulo)
- Floor division

It also handles division by zero gracefully instead of crashing — if the second number is 0, it just prints a message saying division isn't possible instead of throwing an error.

## How to run it

Make sure you have Python 3 installed, then run:

```bash
python Basic_Calculator.py
```

You'll be asked to enter two numbers, and it'll print out all the results at once.

## Example

```
Enter a number: 10
Enter a number: 3
The sum of the two numbers is: 13.0
The difference of the two numbers is: 7.0
The product of the two numbers is: 30.0
The power of the two numbers is: 1000.0
The division of the two numbers is: 3.3333333333333335
The remainder of the two numbers is: 1.0
The floor division of the two numbers is: 3.0

Thank you so much for using this calculator
```
